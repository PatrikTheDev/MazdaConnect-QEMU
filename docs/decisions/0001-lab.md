# 0001: Docker toolchain and staged rehosting

Use just as the host entry point and Docker Compose for a native-host-architecture
Linux tool container. Pin the base image by digest and packages by Debian snapshot.
Keep Linux working trees in a named volume; bind-mount source read-only.

Use QEMU TCG without KVM/nested-virtualization requirements. Validate individual
ARM executables before full-system rehosting. Start with virt and a supported kernel.
Original Mazda kernel/board emulation remains a separate research path.

Expose a future working guest display over VNC; run the Ghidra UI natively.
Confirm ABI and graphics dependencies before choosing firmware toolchains or shims.
